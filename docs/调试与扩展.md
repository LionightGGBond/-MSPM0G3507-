# 调试与扩展

## 首次上板

1. 配置SysConfig、生成、编译。首次让车轮架空；**当前默认连续循迹（ROBOT_MOTOR_TEST_MODE=0），初始化后等待2秒开始，两轮正向PWM最低10%，不按时长停车**。IMU离线不阻止运行。需要转2秒/停2秒的台架测试时，把该宏改为1、重新编译下载，详见 [电机循环测试与串口诊断](电机循环测试与串口诊断.md)。
2. 遮挡黑线，屏幕LINE从左到右依次应是10000、01000、00100、00010、00001。中央单线为00100；程序位图仍是bit0最左。
3. 手转轮子，查看 `s_encoder` 或 `RobotSnapshot`。物理前进必须是正计数。编码器反向改 `ENCODER_SIGN`，电机反向改 `MOTOR_SIGN`，不要用负PID增益修正接反。
4. 使用现有测试模式，将TEST_LEFT_PWM或TEST_RIGHT_PWM设0可逐轮测试，无需替换main。确认“命令正值=前进=编码器正计数”再恢复循迹闭环。

5. 示波器检查PB15/PB16约20kHz，命令越大高电平越宽；停车方向脚11为短路制动。
6. 静止停车阶段MPU采100个连续稳定样本标定零偏。OLED的CAL进度一直重置时检查振动、安装与I2C；可在停车状态继续标定。OLED默认0x3C、MPU默认0x68，按模块核对地址和上拉。三行角度显示及滤波参数见 [IMU说明](IMU角度与互补滤波.md)。
7. 中线时目标20/20，黑线左偏则左轮目标降低、右轮保持20。先调低速PID，再落地。
8. 默认移开黑线、全黑或非九种标准线型均保持最近差速，OLED显示HOLD:1；恢复有效线型后立即跟随，HOLD:0。启动时尚无有效线型则目标10/10低速直行。默认不会锁存LOST/CROSS。
9. `ROBOT_STOP_ON_INVALID_LINE=1`才恢复无效线型停车锁存；`ROBOT_STOP_ON_ENCODER_STALL=1`才启用反馈缺失停车。`ROBOT_RUN_MS=0`持续运行，改100000U才在100秒结束停车。程序异常停车保护仍保留。

## 单位与调参

速度单位是四倍频计数/10ms，沿用原STM32单位；不知道减速比时不猜测m/s。
若需换算：`轮速(m/s)=delta×πD/(4×PPR×G×0.010)`，D为轮径米，G为减速比，PPR为电机轴单相每转完整周期数。
原头文件写11线，具体定义和减速比须以实际电机资料/测量为准。

PID系数仍需重调。修改采样周期或倍频必须重新整定；零目标清积分，大误差积分分离，输出饱和抑制同向积分。
反转命令先制动一个10ms周期，屏幕PWM是PID命令值，制动期间实际输出不同。

## 诊断

| 状态 | 含义 |
| --- | --- |
| WAIT / RUN / DONE | 等待2秒 / 连续循迹 / 配置非零时限才会运行结束 |
| TEST RUN / TEST STOP / TEST PAUSE | 开环转动 / 周期刹车 / 串口手动暂停；不执行循迹和速度PID |
| LOST | 只有STOP_ON_INVALID_LINE=1时，五路无黑线才会锁存停车 |
| CROSS/INVALID | 非九种标准线型；只有STOP_ON_INVALID_LINE=1时锁存停车 |
| ENC STALL | 命令绝对值≥35%且连续500ms无反馈；STOP_ON_ENCODER_STALL=1时才因此停车 |
| HOLD:1 / 串口保持差速=1 | 无效线型，保持最近有效差速；恢复线型后自动更新 |
| MAIN TIMEOUT | 主循环超过250ms未更新心跳，控制中断停车 |
| PWM CONFIG / CTRL CONFIG | PWM/控制定时器参数校验失败；底部显示实际LOAD值 |
| TICK ERROR | 控制ISR已启动，但10ms间隔偏差超过2ms |
| 快照中right_invalid_transitions增加 | 右轮AB同时跳两位，可能漏边沿/干扰/服务不及时 |
| IMU:xx NO REPLY / TIMEOUT / BAD ID等 | 初始化或近期I2C失败，xx是地址；底盘仍可独立循迹 |

GPIO中断标志不能排队多个边沿，非法跳变也检不出所有漏计。
高速验证须用参考脉冲/逻辑分析仪对比：`边沿频率=电机轴RPM×PPR×4/60`。
若超出处理能力，应调整解码或外加计数器，不能从编译通过推断最高转速计数正确。
主循环超时停车依赖控制中断仍可执行，不是硬件急停或独立看门狗；STBY仍按既定接法固定高。

OLED、IMU、UART在主循环，快照和读计数使用短临界区；UART已有非阻塞TX缓冲，不在控制ISR里等待整包或刷新屏幕。
MPU姿态目前仅显示。四元数互补滤波输出ZYX欧拉角：Pitch绕Y轴、Roll绕X轴，Yaw为相对航向。轴向以芯片资料和实测为准，安装方向改变要做坐标变换。Yaw没有磁力计校正，会漂移。

## K230和云台

原K230预留的UART0 PA10/PA11现用于Type-C调试（板载CH340E），后续K230需要另选串口或处理硬件隔离，不能把两个TX直接并到PA11。当前没有假定K230帧格式或视觉接管底盘。
确定协议时需给帧头、长度、类型、坐标单位、校验与有效期；主循环校验解析，控制ISR读一致性快照，过期目标不能继续当作新数据。

云台预留UART1 PA8/PA9、CAN PA12/PA13、TIMA0/TIMA1。有闭环驱动器后按其接口编写位置/速度命令。
若需MCU直接做三相FOC，还涉及三相功率驱动、电流采样、ADC同步、编码器与保护，必须重新审核资源。SPI当前只表示外设空闲，不承诺最终引脚组合可同时满足。
