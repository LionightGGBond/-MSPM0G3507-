# IMU角度显示与四元数互补滤波

MPU6050仍使用现有I2C0：PA0=SDA，PA1=SCL，400kHz。无需新增SysConfig外设或更改引脚。
传感器采样100Hz，主循环约每10ms读取一次，OLED约100ms更新一帧；滤波和I2C不进入电机控制中断。

## OLED布局

```text
RUN         H:000012*
PITCH:+ 12.3 deg
ROLL :-  2.1 deg
YAW  :+ 35.6 deg
IMU:OK ACC YAW:REL
LINE:00100 HOLD:0
L T:20 V:20 P:30
R T:20 V:20 P:31
```

上图仅示意数值。三行均带正负号、一位小数，单位为度；内部仍用float，不因显示精度而截断滤波结果。实现使用整数格式化，未启用printf浮点格式。
Pitch约在±90°，Roll/Yaw约在±180°；Yaw越过边界会从+180跳到-180，这是角度表示回绕。
Euler角在Pitch接近±90°时有表达奇异性，内部四元数仍连续，但不能要求Roll/Yaw显示始终连续。

| 屏幕提示 | 含义 |
| --- | --- |
| CAL:xx/100 HOLD STILL | 静止零偏标定中；Pitch/Roll先显示重力倾角，Yaw显示占位符 |
| IMU:OK ACC YAW:REL | 已标定，陀螺预测并使用可信加速度方向校正 |
| IMU:OK GYR YAW:REL | 当前加速度幅值超范围，只做陀螺预测，冻结校正积分 |
| IMU:WAIT GRAVITY | 尚无可用初始姿态，需要一次可信重力采样 |
| IMU:69 NO REPLY E:n | 默认已先后探测0x68、0x69，未取得有效应答；检查电源、共地、SDA/SCL及上拉 |
| IMU:xx TIMEOUT E:n | 等待总线或事务超时；检查信号是否被拉低及连接 |
| IMU:xx BAD ID:yy | 有应答但WHO_AM_I不是0x68；核对模块型号，不当作MPU6050直接配置 |
| IMU:xx RESET / CONFIG / READ E:n | 复位、配置或采样阶段失败，累计错误数为n |

T=目标编码器计数/10ms，V=实测计数/10ms，P=有符号PWM命令百分数。
右编码器的非法跳变次数保留在 `RobotSnapshot.encoder.right_invalid_transitions` 中，可用调试器查看。

## 心跳与定时器故障诊断

右上角 `H:000012*` 表示应用启动后已过12个完整秒，`*`表示PA22心跳灯处于亮相位。每秒亮500ms、灭500ms，进入下一次亮相位时计数加一。OLED约100ms更新一帧，星号显示相应存在刷新延迟。
计数依赖SysTick和主循环，不依赖电机控制中断；故障停车仍递增。屏幕显示低6位，超过999999后显示回绕，内部为32位计数。
心跳递增说明时基与主循环仍在运行，不能据此认定控制中断或IMU通信正常。

| 顶部状态 | 底部显示 | 含义 |
| --- | --- | --- |
| PWM CONFIG | PWM:实际LOAD CT:控制LOAD；IRQ次数、DT毫秒 | 电机PWM的时钟或周期校验未通过，控制ISR未启动 |
| CTRL CONFIG | 同上 | 10ms定时器配置未通过，控制ISR未启动 |
| TICK ERROR | 同上 | 已启动控制ISR，但实际间隔偏离10ms超过2ms |

当前目标PWM LOAD=1599、控制LOAD=9999。**PWM Period Count应填写1600；它不同于两通道Counter Compare Value=1599。** 如果PWM Period Count误填1599，SDK生成LOAD=1598，程序会停车，新屏幕显示 `PWM CONFIG` 和 `PWM:1598 CT:9999`。
LINE现在始终读取当前GPIO，即使控制ISR没有启动也可以遮挡传感器检查输入。

IMU初始化失败不再清除累计错误数。默认优先探测 `ROBOT_MPU_ADDRESS`，无应答再尝试另一个68/69地址；成功后所有事务使用实际地址，WHO_AM_I仍须为0x68。可用 `ROBOT_IMU_AUTO_ADDRESS=0` 关闭自动地址探测。

## 通信失败定位

日志为“在线=否、芯片标识=0xFF、末次采样=0ms、总线=硬件通信错误(2)”表示尚未读到有效IMU数据；此时屏幕显示角度占位符是预期行为。0xFF是探测前设置的无效初值，不能当作真实芯片ID。最终地址显示0x69只表示最后尝试地址，不表示0x69确实有器件。

当前SysConfig约定：I2C0，PA1=SCL、PA0=SDA，Controller模式，BUSCLK32MHz分频1。两脚都是开漏用途，需要外部上拉。模块供电要按实际板卡电路核对，MCU侧信号仍按3.3V约定；不要在不清楚模块稳压器和上拉电源时盲目改成5V供电。

串口先发 `s`，确认“测试暂停”后发 `i`。新版本日志的SCL/SDA来自I2C控制器MBMON总线监视寄存器；旧版本从GPIO DIN读已复用引脚，旧日志0/0不能直接证明物理电平为低。用万用表测模块供电和空闲SCL/SDA进行交叉确认。

新增“IMU探测”分别保留0x68/0x69的结果、标识、阶段和MSR；I2C驱动在恢复控制器前保存MSR，OLED总线不会覆盖该记录。MSR位定义：bit1=总错误、bit2=地址未应答、bit3=数据未应答、bit4=仲裁丢失；尤其ADRACK/DATACK置1表示NACK。等待总线空闲超时、发送寄存器时地址未应答、接收数据时失败，需要分别排查，不宜全部归因于滤波算法。

| 实测/新诊断现象 | 下一步 |
| --- | --- |
| 模块供电不符合板卡要求或不共地 | 先修正供电与GND，核对板载稳压器输入/输出 |
| 空闲SCL/SDA不接近3.3V | 核对上拉、短路、接反、模块未供电或总线被拉住；先用仪表确认 |
| 两根线空闲高，但两个地址均地址未应答 | 核对PA1→SCL、PA0→SDA、AD0、实际芯片型号；必要时用逻辑分析仪确认时钟及第9位ACK |
| WHO成功读回但不是0x68 | 按实际芯片资料选择驱动，不盲目放宽ID检查 |
| 通信正常但标定不断清零 | 停止电机并保持板卡静止，检查振动和样本是否连续 |

没有仪表结果和新的探测日志时，只能确认通信失败，不能断言模块损坏或某一根线接错。可在用户SysConfig界面将IMU_I2C总线从400k临时改为100k、保存Build下载，降低对线长和上拉上升时间的要求；OLED配置不必随之修改。这是排查手段，不代表400k本身不被MPU6050支持。

## 算法

采用六轴、四元数形式的显式互补滤波。陀螺仪角速率扣除静止零偏后进行姿态预测；用归一化加速度方向与预测重力方向的叉积，形成PI角速率修正，最后归一化四元数并输出ZYX欧拉角。
这是Mahony风格的重力互补观测器，没有加入磁场观测；算法背景见作者论文 [Nonlinear Complementary Filters on the Special Orthogonal Group](https://researchportalplus.anu.edu.au/en/publications/nonlinear-complementary-filters-on-the-special-orthogonal-group/)。

使用三轴联动的四元数运动学，避免分别把机体gx/gy/gz直接当成任意倾角下的Euler角变化率。
每次积分使用实际时间差。I2C失败或两次采样间隔超过50ms时，不把漏采期间按恒定角速率补积分；下一次可信加速度重建倾角，并保留最近相对Yaw参考。断线期间发生的Yaw变化无法补回。

加速度模长在0.85g到1.15g外时停止重力校正。该判断不能排除所有线性加速度，例如水平加速仍可能处于此范围；真实行驶时仍需调参和验证。
仅靠重力没有绝对航向参考，Yaw即使滤波、标定后仍可能漂移；不能把它直接当作长时间无漂移的航向或完整转数。

## 参数入口：robot_config.h

| 宏 | 默认值 | 调整含义 |
| --- | --- | --- |
| ROBOT_IMU_CF_KP | 2.0 | 重力校正比例增益。增大收敛更快，也更容易跟随振动/加速度误差 |
| ROBOT_IMU_CF_KI | 0.02 | 缓慢修正残余零偏；设0关闭在线积分修正 |
| ROBOT_IMU_CF_I_LIMIT_DPS | 3.0 | 每轴积分角速率校正上限，°/s |
| ROBOT_IMU_ACCEL_MIN_G / MAX_G | 0.85 / 1.15 | 接受重力校正的模长范围，g |
| ROBOT_IMU_MAX_DT_MS | 50 | 最大允许积分间隔，ms |
| ROBOT_IMU_CALIBRATION_SAMPLES | 100 | 连续静止采样数，默认约1秒 |
| ROBOT_IMU_CAL_MAX_DPS | 3.0 | 标定时允许的原始每轴角速率上限，°/s |
| ROBOT_IMU_CAL_STD_DPS | 0.5 | 标定窗口内每轴角速率标准差上限，°/s |

开始标定须处于非RUN状态、两轮增量为零，并满足加速度及角速率门限；出现运动、通信中断或窗口方差超标会重新计数。轮子不动并不代表手持板卡不动，因此仍需人为保持静止。
初始角速率零偏超过门限时，应在确认板卡完全静止后调整阈值，不能靠调大门限掩盖旋转。
更改采样周期时还要同步修改MPU6050的SMPLRT_DIV；当前9对应100Hz。

## 验证

先架空车轮：现有程序初始化后等待2秒会自动运行，避免手持传感器测试时车辆移动。
平放静置完成标定，检查Pitch/Roll接近0°、Yaw起点接近0°；分别绕芯片X/Y轴倾斜，观察Roll/Pitch符号和变化方向；保持水平绕Z轴旋转，观察相对Yaw。
这些角是芯片坐标下的姿态，模块装到车辆上后需依据实际芯片轴向做坐标映射。
验证在有振动、电机通电及车辆加速时是否满足显示稳定性，再调整增益。当前姿态没有接入底盘转向PID。
